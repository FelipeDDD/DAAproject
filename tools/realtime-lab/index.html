Reliable and unreliable APIs both use ordered TCP/WebSocket here. Lab simulation delays/drops whole gameplay messages in both directions, including reliable projectile events; it never changes TCP. Welcome, membership and RTT probes bypass simulation. Server RTT measures client to relay only. Peer RTT measures client to relay to remote browser to relay to client, once per second per peer, bypassing simulated delay/loss. Both are application round trips, not packet loss.
